Our promises

Install it on a hundred client sites without wondering what it will show or become.

  • No nags, no "pro"No admin notices outside its own screens, no review requests, no upsells. Complete and free.
  • No trackingNo telemetry and no remote requests: no fonts, scripts or banners from anywhere else.

  • AccessibleWorks without JavaScript, with a keyboard and a screen reader; light and dark.

For developers

A REST API, WP-CLI for every admin action, Abilities API registrations for AI agents, and hooks for everything that happens.

WP-CLI

wp ruvelo-feedback request list --status=planned
wp ruvelo-feedback request status 42 shipped \
    --note="Live for everyone today."
wp ruvelo-feedback request merge 51 --into=42
wp ruvelo-feedback changelog publish 60
